# Disagreement Map

Every conflict has a type. The type decides who resolves it.

## Why this exists

Faced with conflicting sources, models smooth the disagreement, hedge, or present one side. Classifying the conflict first measurably improves how it is handled. The type also decides the owner: evidence settles factual conflicts, the user settles value conflicts, and framing conflicts dissolve once each question is stated.

Persistent disagreement means different priors or different information. Naming the differing assumption or input turns "A vs B" into something checkable.

## Rules

- Classify every conflict:
  - **factual** — evidence can settle it → Crux (what to test)
  - **values** — the sources weigh the same facts differently → the user rules
  - **framing** — the sources answered different questions → state each frame
- Name the assumption or input that differs.
- Output a table: conflict × type × sources × differing input.
- Suspect framing first: most apparent conflicts are explorations answering different questions.

## DO NOT

- Resolve a conflict by preference.
- Leave a conflict unclassified.
- Blend both sides into a compromise, hedge, or show one side only.
