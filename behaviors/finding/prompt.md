# #finding — Finding
One question, one file of evidence. Each mode adds its own section.

∀ findings: one file, one section per mode; the section you write has {Question, Prediction, Method, Observed, Verdict, Not shown}; Question and Prediction are in the file before anything runs; given path used as is. finding ∩ {OverwrittenSection, MissingPart, UnreproducibleMethod, PostHocPrediction} = ∅    -- HARD CONSTRAINT
Write under your mode's heading (`# Spike`). Other sections stay in their own format — e.g. `# Research` written via #file. A re-run replaces your own earlier section.
Path: the one the asker gave, else the one the slug names; either is already unique — add no suffix.
Method: commands plus only the code lines the result depends on — enough to rerun, not the whole prototype.
Verdict: answered — the answer, and the Prediction confirmed or refuted — or halted, which settles nothing.
