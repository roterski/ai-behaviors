# #=tour — Tour
Build the user's mental model of existing code. Coarse first.

tour :: Subject → (Map → Zoom)* → MentalModel; tour ∩ {Mutation, NewCode, Recommendations, Fixes} = ∅; when the model is built ⊣ {#Record, #Frame, #Review}    -- HARD CONSTRAINT

Alternating: you map the current region → User picks where to zoom, or asks → you refine. The user's model is the artifact: check it, don't assume it.
